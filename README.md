# BikeGrid

Велокомпьютер для Android: запись тренировок по GPS, навигация по маршрутам, подключение BLE-датчиков и анализ результатов. Работает на Android 9 (API 28) и новее, интерфейс на русском и английском языке.

Приложение не требует регистрации и аккаунта. История тренировок, настройки и маршруты хранятся локально на устройстве.

## Возможности

### Запись тренировки
- Езда на велосипеде, бег и ходьба; GPS-скорость, дистанция, время и время в движении, набор высоты.
- Автопауза при остановке и автоматическое возобновление движения, ручные и автоматические круги.
- Восстановление незавершённой тренировки после перезапуска приложения.
- Настраиваемые плитки метрик, компактный режим, экран карты или цифровой экран.
- Экран остаётся включённым во время записи; фоновая работа через foreground service с уведомлением.
- Симулятор датчиков доступен только в debug-сборках.

### Карта и маршруты
- Карта osmdroid, офлайн-кэш тайлов, переключение источников карты.
- Импорт маршрутов из GPX и FIT, отображение трека на карте, навигация.
- Предупреждение о сходе с маршрута, расстояние и направление возврата, профиль высоты и остаток пути.

### Датчики и тренажёр
- Подключение BLE-датчиков: пульс, скорость/каденс, мощность, уровень заряда, беговой RSC.
- Автоматическое переподключение ранее использованных датчиков.
- Умный велостанок по FTMS: режимы ERG и Resistance, задание мощности, быстрая подстройка.
- При потере GPS скорость берётся от датчика скорости или велостанка.

### Тренировки по плану
- Библиотека структурированных тренировок и редактор.
- Импорт файлов `.ZWO`, плеер шагов с целевой мощностью или зоной пульса.
- Автоматические круги на переходе между шагами, обратный отсчёт перед стартом шага.

### Аналитика и история
- История тренировок с фильтрацией по типу; детальный экран с KPI, графиками, зонами и кругами.
- Зоны пульса и мощности, нормализованная мощность (NP), IF, TSS, калории, время в зонах.
- Графики скорости, пульса, мощности и высоты, распределение по зонам.

### Обмен данными
- Экспорт тренировки в GPX, TCX или FIT в папку «Загрузки/Bike_» с отправкой через меню «Поделиться».
- Импорт и экспорт тренировок из Health Connect (если приложение установлено и разрешения выданы).
- Кнопка «Отправить на часы»: публикует уведомление со сводкой последней тренировки, которое дублируется на подключённых умных часах. Отдельное приложение на часах не требуется.
- Резервная копия и восстановление: все тренировки, маршруты, настройки и данные профиля в одном JSON-файле.
- «Показать все BLE-устройства» для нестандартных датчиков.

## Разрешения и приватность

| Разрешение | Зачем нужно |
|---|---|
| Геолокация (в т.ч. в фоне) | Запись GPS-трека, скорости и навигация во время тренировки |
| Bluetooth | Подключение датчиков пульса, скорости, мощности и велостанка |
| Уведомления | Фоновая запись тренировки и отправка сводки на часы |
| Активность/шаги | Подсчёт шагов для бега и ходьбы |
| Health Connect | Необязательный импорт/экспорт тренировок (только после вашего согласия) |
| Файлы | Импорт GPX/FIT/ZWO и сохранение бэкапов через системный выбор файлов |

Все разрешения запрашиваются по шагам с пояснением. Приложение не передаёт ваши тренировки на собственный сервер. Для загрузки карт требуется интернет (или предварительно сохранённый кэш тайлов); остальные функции работают без сети. В release-сборке включён Crashlytics для сбора отчётов о сбоях.

## Установка

- Готовый APK: вкладка [Releases](https://github.com/acab1981-netizen/BikeGrid/releases).
- RuStore: файл из каталога `store/rustore/`.

Минимальная версия Android — 9. Разрешите установку из неизвестных источников, если ставите APK напрямую.

## Сборка из исходников

Нужны JDK 17 и Android SDK (platform 36, build-tools 36.0.0).

```powershell
.\gradlew.bat testDebugUnitTest assembleRelease
```

Релиз подписывается ключом из `android/key.properties` и `android/release-key.jks` (не хранятся в репозитории). Без них CI собирает APK с debug-подписью — для публикации используйте подписанный APK из Releases.

Чтобы CI тоже собирал подписанный APK, добавьте в настройках репозитория **Settings → Secrets and variables → Actions → New repository secret** четыре секрета:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | `android/release-key.jks`, закодированный в base64 одним потоком: `base64 -w0 release-key.jks` (Linux) или `[Convert]::ToBase64String([IO.File]::ReadAllBytes("release-key.jks"))` (PowerShell) |
| `KEY_STORE_PASSWORD` | пароль keystore |
| `KEY_ALIAS` | `rustore-key` |
| `KEY_PASSWORD` | пароль ключа |

Workflow (`Configure release signing`) сам создаст `android/key.properties` и проверит алиас через `keytool`. Если секреты не заданы, сборка продолжается с debug-подписью и в логе выводится пояснение.

Основные компоненты: Kotlin, Jetpack Compose, Room, Coroutines/Flow, osmdroid, Nordic BLE, Android Health Connect, Firebase Crashlytics. Сборка и тесты выполняются в GitHub Actions (`.github/workflows/android.yml`).
